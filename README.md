Данный проект является домашним заданием по теме Объектно Ориентированного Программирования.  
В данном проекте описаны основные свойства двух классов **Product** и **Category**.

### Класс Product  
Каждый объект класса содержит поля:  
**name** - название продукта  
**description** - описание продукта  
**__price** - приватный атрибут цены продукта  
**quantity** - количество продукта.  

#### Методы класса Product  

**\_\_init__** - метод инициализации нового объекта класса Product. При передаче аргументов важно соблюсти условия:
name и description - тип данных str, price - положительное число типа int или float,
quantity - неотрицательное число типа int. При несоблюдении данных условий метод возбуждает исключение ValueError.  

**price** - одноименные геттер и сеттер приватного атрибута __price. Геттер возвращает текущее значение цены продукта.
Сеттер позволяет установить новое положительное значение цены,
при снижении цены запрашивает у пользователя подтверждение на данное снижение. Выводит в консоль IDE соответствующее
сообщение о результате вызова. Сеттер ничего не возвращает.  

**new_product** - класс-метод, позволяющий создавать новый объект класса из словаря,
в котором названия ключей совпадают с именами параметров метода \_\_init__.
При отсутствии в словаре ключей 'name' или 'description' возбуждается исключение ValueError.
При отсутствии ключей 'price' или 'quantity' значения соответствующих параметров метода \_\_init__ принимаются равными
0.0 и 0 соответственно. Также значение 0.0 параметра price в последствии приведет к возбуждению исключения ValueError.

### Класс Category  
Каждый объект класса содержит поля:
**name** - название категории продуктов  
**description** - описание категории продуктов
**__products** - приватный атрибут, списка продуктов определенной категории.
В данном списке все элементы относятся к классу Product.  
Также данный класс содержит счетчики:
**category_count** - общее количество объектов класса  
**product_count** - суммарное количество товаров во всех категориях класса.

#### Методы класса Category  

**\_\_init__** - метод инициализации нового объекта класса Category. Важно отметить, что опциональный параметр products  
может быть только списком объектов класса Product, иначе будет возбуждено исключение TypeError.  

**products** - геттер приватного атрибута __products. Метод выводит в консоль IDE форматированную строку для
каждого объекта в списке продуктов категории. При этом метод ничего не возвращает  

**products_list** - также геттер приватного атрибута __products. Возвращает список объектов класса Products категории.  

**add_product** - метод добавления объекта класса Product в список продуктов категории. Метод проверяет существующий  
список продуктов на наличие объекта с идентичным аттрибутом name.  
В случае первого совпадения новый продукт не добавляется в список,
атрибут существующего продукта quantity увеличивается на значение этого же атрибута добавляемого продукта.  
Также, значение атрибута __price существующего продукта принимается большим из собственного значения и значения
того же атрибута нового продукта.  

### Модуль utils.py
В данном модуле определена функция **extract_categories**, которая извлекает данные из JSON-файла и
возвращает список объектов класса **Category**.
В свою очередь, каждый объект категории в качестве списка продуктов содержит список объектов класса **Product**.
